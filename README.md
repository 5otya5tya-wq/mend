mend is one patch tool for every AI edit format: it applies unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edits to a directory tree — all-or-nothing per edit, with three-tier line matching (exact, trailing-whitespace-insensitive, and trimmed with re-indentation).

## Run it

```sh
node main.ts [options] [tree] < edit.patch
```
